# PDFStrike independent acceptance files

These PDFs are self-authored test data generated by `generate.py` using the locally bundled ReportLab 4.4.9 and pypdf 6.10.0. The script uses standard PDF fonts and no borrowed images, logos, personal data, or hosted service. It is test tooling, not application code. Re-running the producer may change PDF metadata and hashes; the checked-in bytes below are the fixtures for this checkpoint.

| --- | --- | --- |

| `form-real.pdf` | Interactive `contact.name` text field and `approved` checkbox with widget appearances. | `b722d6e3facb821511e95146aabf6f8b704337a51aa0cd9c6affd42da06e7a20` |
| `native-compat.pdfstrike` | CLI-created archive from `packet-real.pdf` with page 2 rotated 90°; checks that the native project crate reads the same edit history. | `9fd1f8d7dc2245f2ba29d5b88d16854dd60b87d0629c5427bf5810e56d2a18be` |

`apps/pdfstrike/tests/real_files.rs` imports both bytes, saves and reopens a `.pdfstrike` project, exports a separate PDF, and checks page/field structures. Independent pypdf and Poppler results are recorded in `apps/pdfstrike/IMPLEMENTATION.md`. This corpus does not cover malicious files, signatures, XFA, accessibility or cross-platform behavior.
